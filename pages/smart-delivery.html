Frequently asked questions

Common questions about Smart Delivery.

Which couriers are supported?

SmartLane connects to 16+ couriers across Pakistan — including TCS, Leopards, Trax, M&P, BlueEx, and others. The exact list can change as we add partners; you always book and track from one dashboard.

Can I print labels automatically?

Yes — generate and print labels in bulk across all couriers, with consistent formatting. No more reformatting for each courier portal.

How is this different from using each courier’s own portal?

Each portal only shows that courier’s parcels. SmartLane is one screen for every partner you use — so support and ops answer customers from a single place.
